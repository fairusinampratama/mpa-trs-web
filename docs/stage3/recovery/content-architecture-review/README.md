## Executive finding

The frontend has a useful canonical graph, but its authoring grammar is incomplete. TE has a dedicated journey structure; BATAFIA is classified as basic education without its recurring programme/edition identity; PD executions have cohort associations without an explicit cycle context. Those are semantic and editorial gaps, not a demand for another framework.

Recommend one small authoring model: **recurring programme → identifiable occurrence**, with optional **separately documented child executions**, and optional **dated phases/sessions inside an occurrence**. Programme, cohort and year are different concepts. Independent activities require none of those parents. Works, sources and context-specific media permissions remain independent. An occurrence is the actual activity/edition/cycle being managed, not an extra manually duplicated page record.

Evidence supports BATAFIA as recurring basic education and PD as a cohort-associated cycle with distinct divisional executions. Whether to elevate both into managed programme/cycle experiences is a proposed amendment requiring approval. It is not already applied to the site.
