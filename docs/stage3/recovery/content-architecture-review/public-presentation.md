## Correction walkthrough

Editor corrects one cycle purpose → saves draft revision → impact preview shows cycle overview and children using the context → reviewer checks source → publisher replaces snapshot. No five-way retyping. Changing a source assertion is not permission to rewrite every public sentence: impacted claims are reviewed. Work title corrections update all referencing links via one work ID after publication; body restrictions stay intact. Withdrawing GH homepage use removes that image only there, without withdrawing its separately approved activity-detail use or RC image.
