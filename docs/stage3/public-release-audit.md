## Publishing choice

- **A: existing repo public + Actions Pages**: one repository, direct short-lived Pages token; exposes Laravel source, all reachable infrastructure history, PRs and metadata. Would require accepting/sanitizing the above disclosures and verifying live public Actions controls. Rejected for this checkpoint.
- **B: private source + public compiled artifact repo**: selected. One added repository plus a preview-only fine-grained credential. Existing source, infrastructure, private ledger and production workflows remain private. Public branch serves compiled assets; no second frontend or dependency build in public repo. Normal GitHub Free Actions quota still applies to the private source build; no paid overage authorized.
- **C: Cloudflare Pages**: would add another service/integration; unnecessary while B is practical. No account or project created.

GitHub Free supports Pages on public repositories: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages . Fork pull_request restrictions: https://docs.github.com/en/actions/reference/security/securely-using-pull_request_target . Custom Pages workflow permissions: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages . Option B instead uses target branch publishing and does not need pages/id-token writes in the private workflow.
